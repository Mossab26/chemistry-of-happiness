## 🚀 كيفية الاستضافة المباشرة على GitHub Pages (مجاناً 100%)

تم تجهيز هذا المشروع ليعمل فوراً كموقع ثابت فائق السرعة على **GitHub Pages** عبر سير عمل مؤتمت (**GitHub Actions**)، دون الحاجة لأي خادم Node.js أو إعدادات معقدة.

### الخطوة 1: رفع المشروع إلى مستودع GitHub الخاص بك
```bash
git init
git add .
git commit -m "Initial commit: Chemistry of Happiness Club Website"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### الخطوة 2: تفعيل GitHub Pages من إعدادات المستودع
1. توجّه إلى مستودعك على GitHub، ثم اضغط على **Settings** (الإعدادات).
2. من القائمة الجانبية اليسرى، اختر **Pages**.
3. تحت قسم **Build and deployment**، غيّر خيار **Source** إلى:
   👉 **GitHub Actions**
4. هذا كل شيء! سيبدأ سير العمل الموجود في `.github/workflows/deploy.yml` ببناء الموقع ونشره تلقائياً خلال دقيقة واحدة.
5. سيظهر لك رابط موقعك المباشر:  
   `https://USERNAME.github.io/REPO_NAME/`

## ✨ المميزات المدمجة (تعمل 100% Offline على GitHub Pages)

- **المساعد الطلابي الذكي «رفيق السعادة»**:
  - محرك استرجاع محلي مستقل مدمج (0ms Latency) يجيب بودّ وعفوية بالدارجة الجزائرية كزميل جامعي متعاون.
  - لا يحتاج لأي مفاتيح خارجية أو خوادم خلفية.
  - يدعم التفاعل الصوتي (استماع ونطق بالمتصفح).
- **مجسم الروبوت المكتبي ثلاثي الأبعاد**: مبني بـ Three.js بحركات تفاعلية و7 حالات تعبيرية.
- **أرشيف الأنشطة الـ 49 (2024 - 2026)**: توثيق شامل للورشات والفعاليات، المعارض، حملات التشجير، والمشاركات الوطنية.
- **لوحة الإدارة التفاعلية**:
  - محمية برمز مرور افتراضي (`happiness2026`).
  - حفظ التعديلات وإضافة الأنشطة محلياً في المتصفح (`localStorage`).
  - تصدير كامل الأرشيف بصيغة ملف `JSON`.
- **تصميم Minimal Luxury**:
  - ألوان النادي الأكاديمية الفاخرة (البني الداكن، البيج العاجي، والذهبي الهادئ).
  - متوافق مع كافة الأجهزة وشاشات الهواتف والحواسيب.
